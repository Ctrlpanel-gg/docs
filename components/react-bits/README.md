# React Bits components

PillButtonContent adapts the rising circular fill and rolling label animation from [Pill Nav](https://reactbits.dev/components/pill-nav) for the hero links. Its styles live in `app/landing.css`; it keeps the existing button styling, link semantics and star count, supports keyboard focus and reduced motion, and needs no animation runtime. Source: [PillNav.jsx](https://github.com/DavidHDev/react-bits/blob/main/src/content/Components/PillNav/PillNav.jsx), [PillNav.css](https://github.com/DavidHDev/react-bits/blob/main/src/content/Components/PillNav/PillNav.css).
