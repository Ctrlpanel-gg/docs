# React Bits components

PillButtonContent adapts the rising circular fill and rolling label animation from [Pill Nav](https://reactbits.dev/components/pill-nav) for the hero links. Its Tailwind classes live in `components/landing/landing-styles.ts`; it keeps the existing button styling, link semantics and star count, supports keyboard focus and reduced motion, and needs no animation runtime. Source: [PillNav.jsx](https://github.com/DavidHDev/react-bits/blob/main/src/content/Components/PillNav/PillNav.jsx), [PillNav.css](https://github.com/DavidHDev/react-bits/blob/main/src/content/Components/PillNav/PillNav.css).

The original license is in LICENSE.md.

The landing footer uses [Gradient ASCII](https://reactbits.dev/backgrounds/gradient-ascii), from the official [GradientASCII TypeScript source](https://github.com/DavidHDev/react-bits/blob/main/src/ts-default/Backgrounds/GradientASCII/GradientASCII.tsx). Its horizon uses a centred circle computed from the viewport width and sagitta, with symmetric lighting and separate palettes/contrast for both themes. It loads near the viewport, pauses offscreen, respects reduced motion and caps pixel density at 1.25. Cleanup releases its GPU resources without forcing context loss, allowing React Strict Mode to remount the same canvas.

`AsciiTechWordmark` adapts the spring-following frame, centre expansion, corner handles and particles from [Tech Text](https://reactbits.dev/text-animations/tech-text) and its [TypeScript source](https://github.com/DavidHDev/react-bits/blob/main/src/ts-default/TextAnimations/TechText/TechText.tsx). The original ASCII stays fully visible. Hover adds a subtle highlight following the actual font contours of that letter's ASCII strokes; it never replaces the art with a different glyph. Highlights are cached and rebuilt on resize, font load and theme changes. The frame and highlight sprites use a small 2D canvas; the background remains WebGL. Both components use Tailwind for layout.
