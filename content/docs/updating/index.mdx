## Which path applies?

| Starting point | Next step |
| --- | --- |
| 1.1.x | Review the 1.1.x → 1.2.0 changes, then follow the runbook |
| Already on 1.2.0 | Confirm a newer stable patch is published before planning an update |
| 1.0.x or older | Select your historical documentation and complete the intermediate upgrade path before applying a 1.2 guide |
| Development checkout or modified fork | Compare your own commits, schema, and custom code against the target; do not assume a stock upgrade |

The latest release checked while preparing these guides is **1.2.0**. A guide for future patch upgrades is a procedure, not a claim that a newer release already exists.

## Do not confuse the selector with an updater

Changing the documentation selector only changes the guide you read. It does not update your installation. Verify the starting version from the actual panel checkout, and choose a target release from the upstream release list.
