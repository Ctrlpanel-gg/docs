<div className="api-endpoint"><strong>PUT</strong><code>/api/roles/&#123;id&#125;</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X PUT 'https://panel.example.com/api/roles/{id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '@request.json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `id` | path | Yes | The ID of the role. |

### Request body (application/json)

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | No | The name of the role. |
| `color` | string | No | The hex color of the role. |
| `power` | integer | No | The power level of the role. |
| `permissions` | array | No | The permissions assigned to the role. |
