<div className="api-endpoint"><strong>DELETE</strong><code>/api/notifications/&#123;user_id&#125;</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X DELETE 'https://panel.example.com/api/notifications/{user_id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `user_id` | path | Yes | The ID of the user. |

## Responses

### 200

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `message` | string | No |  |
| `meta` | object | No |  |

### Example

```json
{
  "message": "All notifications deleted successfully",
  "meta": {
    "deleted_count": 10
  }
}
```
