## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X DELETE 'https://panel.example.com/api/notifications/{user_id}/{notification_id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `user_id` | path | Yes | The ID of the user. |
| `notification_id` | path | Yes | The ID of the notification. |
