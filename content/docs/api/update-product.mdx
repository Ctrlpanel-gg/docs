<div className="api-endpoint"><strong>PUT</strong><code>/api/products/&#123;id&#125;</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X PUT 'https://panel.example.com/api/products/{id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '@request.json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `id` | path | Yes | The ID of the product. |

### Request body (application/json)

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | No | The name of the product. |
| `description` | string | No | The description of the product. |
| `price` | number | No | The price of the product. |
| `minimum_credits` | number | No | The minimum credits required to purchase. |
| `memory` | integer | No | The memory in MB. |
| `cpu` | integer | No | The CPU limit in %. |
| `swap` | integer | No | The swap limit in MB. |
| `disk` | integer | No | The disk limit in MB. |
| `io` | integer | No | The IO limit. |
| `serverlimit` | integer | No | The server limit. |
| `databases` | integer | No | The database limit. |
| `backups` | integer | No | The backup limit. |
| `allocations` | integer | No | The allocation limit. |
| `nodes` | array | No | List of node IDs associated with the product. |
| `eggs` | array | No | List of egg IDs associated with the product. |
| `disabled` | boolean | No | Whether the product is disabled. |
| `oom_killer` | boolean | No | Whether the OOM killer is enabled. |
| `default_billing_priority` | integer | No | The default billing priority. |
| `billing_period` | string | No | The billing period. |
