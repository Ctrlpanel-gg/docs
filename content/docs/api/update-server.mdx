<div className="api-endpoint"><strong>PUT</strong><code>/api/servers/&#123;id&#125;</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X PUT 'https://panel.example.com/api/servers/{id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '@request.json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `id` | path | Yes | The ID of the server. |

### Request body (application/json)

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | No | The name of the server. |
| `description` | string | No | The description of the server. |
| `user_id` | integer | No | The ID of the user who owns the server. |
| `billing_priority` | integer | No | The billing priority. |
| `product_id` | string | No | The ID of the product. |
| `egg_id` | integer | No | The ID of the egg. |
| `location_id` | integer | No | The ID of the location. |
| `egg_variables` | object | No | The egg variables for the server. |
