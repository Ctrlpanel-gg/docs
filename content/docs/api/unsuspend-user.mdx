## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X PATCH 'https://panel.example.com/api/users/{user_id}/unsuspend' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '@request.json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `user_id` | path | Yes | The ID of the user. |

### Request body (application/json)

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `reason` | string | No | Re-activation after review. |
