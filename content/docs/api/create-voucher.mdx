<div className="api-endpoint"><strong>POST</strong><code>/api/vouchers</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X POST 'https://panel.example.com/api/vouchers' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '@request.json'
```

### Request body (application/json)

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `memo` | string | No | Description for the voucher. |
| `code` | string | Yes | 4-36 chars, alpha-dash format. |
| `uses` | integer | Yes | Max uses. |
| `credits` | number | Yes | Credits amount. Min: 0.01, Max: 9223372036854775. |
| `expires_at` | string | No | Expiration date (d-m-Y H:i:s or d-m-Y). |
