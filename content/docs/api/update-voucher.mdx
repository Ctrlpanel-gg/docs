<div className="api-endpoint"><strong>PUT</strong><code>/api/vouchers/&#123;id&#125;</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X PUT 'https://panel.example.com/api/vouchers/{id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '@request.json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `id` | path | Yes | The ID of the voucher. |

### Request body (application/json)

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `memo` | string | No | A description for the voucher. |
| `uses` | integer | Yes | The number of times the voucher can be used. |
| `code` | string | No | The unique code for the voucher. |
| `credits` | number | Yes | The amount of credits the voucher gives. |
| `expires_at` | string | No | The expiration date of the voucher (d-m-Y H:i:s or d-m-Y). |
