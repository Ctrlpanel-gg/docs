## Getting started

The CtrlPanel REST API gives you access to users, servers, products, roles, vouchers, and notifications. All 38 endpoints are documented here.

## Authentication

Use a bearer token created in your panel. Include `Authorization: Bearer YOUR_TOKEN` and `Accept: application/json` in your requests. The base URL is your own panel installation.

[Download the complete OpenAPI specification](/openapi/openapi.yaml).
