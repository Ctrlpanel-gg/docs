<div className="api-endpoint"><strong>POST</strong><code>/api/notifications/send-to-all</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X POST 'https://panel.example.com/api/notifications/send-to-all' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '@request.json'
```

### Request body (application/json)

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `via` | string | Yes | The notification channel (mail, database, both). |
| `title` | string | Yes | The title of the notification. Must be at least 1 character. |
| `content` | string | Yes | The content of the notification. Must be at least 1 character. |
