<div className="api-endpoint"><strong>GET</strong><code>/api/vouchers/&#123;id&#125;</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X GET 'https://panel.example.com/api/vouchers/{id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `id` | path | Yes | The ID of the voucher. |
| `include` | query | No | Comma-separated list of related resources to include. <br />Available: <code>users</code> |
| `filter[code]` | query | No | Filter results by code |
| `filter[memo]` | query | No | Filter results by memo |
| `filter[credits]` | query | No | Filter results by credits |
| `filter[uses]` | query | No | Filter results by uses |

## Responses

### 200

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `data` | object | No |  |

### Example

```json
{
  "data": {
    "id": 1,
    "code": "SUMMER2026",
    "memo": "Summer promotion",
    "credits": "50.00",
    "uses": 100,
    "expires_at": "2026-12-31 23:59:59",
    "created_at": "2026-04-26 12:00:00",
    "updated_at": "2026-04-26 12:00:00"
  }
}
```
