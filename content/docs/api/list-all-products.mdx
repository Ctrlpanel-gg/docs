<div className="api-endpoint"><strong>GET</strong><code>/api/products</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X GET 'https://panel.example.com/api/products' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `include` | query | No | Comma-separated list of related resources to include. <br />Available: <code>servers.user</code>, <code>eggs.nest</code>, <code>nodes.location</code> |
| `filter[name]` | query | No | Filter results by name |
| `filter[description]` | query | No | Filter results by description |
| `filter[price]` | query | No | Filter results by price |

## Responses

### 200

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `data` | array | No |  |
| `meta` | object | No |  |
