<div className="api-endpoint"><strong>GET</strong><code>/api/servers</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X GET 'https://panel.example.com/api/servers' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `include` | query | No | Comma-separated list of related resources to include. <br />Available: <code>product</code>, <code>user</code> |
| `filter[name]` | query | No | Filter results by name |
| `filter[suspended]` | query | No | Filter results by suspended |
| `filter[identifier]` | query | No | Filter results by identifier |
| `filter[pterodactyl_id]` | query | No | Filter results by pterodactyl_id |
| `filter[user_id]` | query | No | Filter results by user_id |
| `filter[product_id]` | query | No | Filter results by product_id |

## Responses

### 200

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `data` | array | No |  |
| `meta` | object | No |  |
