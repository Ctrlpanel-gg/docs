<div className="api-endpoint"><strong>GET</strong><code>/api/notifications/&#123;user_id&#125;</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X GET 'https://panel.example.com/api/notifications/{user_id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `user_id` | path | Yes | The ID of the user. |

## Responses

### 200

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `data` | array | No |  |
| `meta` | object | No |  |

### Example

```json
{
  "data": [
    {
      "id": "2491fec3-c7d7-47cd-9d82-cc76e851c124",
      "type": "App\\Notifications\\ServerCreated",
      "details": {
        "title": "Server Created",
        "content": "Your server has been created successfully."
      },
      "read_at": null,
      "created_at": "2026-04-26 12:00:00",
      "updated_at": "2026-04-26 12:00:00"
    }
  ],
  "meta": {
    "total": 1
  }
}
```
