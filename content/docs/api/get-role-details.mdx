<div className="api-endpoint"><strong>GET</strong><code>/api/roles/&#123;id&#125;</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X GET 'https://panel.example.com/api/roles/{id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `id` | path | Yes | The ID of the role. |
| `include` | query | No | Comma-separated list of related resources to include. <br />Available: <code>permissions</code>, <code>users</code> |
| `filter[name]` | query | No | Filter results by name |

## Responses

### 200

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `data` | object | No |  |

### Example

```json
{
  "data": {
    "id": 2,
    "name": "Moderator",
    "color": "#00FF00",
    "power": 50,
    "permissions": [
      {
        "id": 1,
        "name": "admin.roles.read",
        "guard_name": "web",
        "created_at": "2026-04-26 12:00:00",
        "updated_at": "2026-04-26 12:00:00"
      }
    ],
    "created_at": "2026-04-26 12:00:00",
    "updated_at": "2026-04-26 12:00:00"
  }
}
```
