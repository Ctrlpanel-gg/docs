<div className="api-endpoint"><strong>PUT</strong><code>/api/users/&#123;id&#125;</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X PUT 'https://panel.example.com/api/users/{id}' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '@request.json'
```

### Parameters

| Name | Location | Required | Description |
| --- | --- | --- | --- |
| `id` | path | Yes | The ID of the user. |

### Request body (application/json)

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | The name. |
| `email` | string | Yes | The email. |
| `password` | string | No | The password. |
| `credits` | number | No | The credits for the user. |
| `server_limit` | integer | No | The server limit for the user. |
| `role_id` | integer | No | The role ID. |
| `referral_code` | string | No | Referral code of the user. |
| `pterodactyl_id` | integer | No | Linked Pterodactyl ID of the user. |
