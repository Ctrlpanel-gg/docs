<div className="api-endpoint"><strong>POST</strong><code>/api/users</code></div>



## Authentication

Send your API token in the `Authorization: Bearer YOUR_TOKEN` header.

## Request

```bash
curl -X POST 'https://panel.example.com/api/users' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '@request.json'
```

### Request body (application/json)

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Min 4, max 30 chars. |
| `email` | string | Yes | Valid email address. |
| `password` | string | Yes | Min 8 chars. |
| `credits` | number | No | Initial credits. Max: 9223372036854775. |
| `server_limit` | integer | No | Initial server limit. Use 0 for unlimited. |
| `role_id` | integer | Yes | Valid role ID. |
| `referral_code` | string | No | Referral code of the user. |
