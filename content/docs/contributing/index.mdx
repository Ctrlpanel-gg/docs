Read the upstream [Code of Conduct](https://github.com/Ctrlpanel-gg/panel/blob/development/.github/CODE_OF_CONDUCT.md), [contribution guide](https://github.com/Ctrlpanel-gg/panel/blob/development/.github/CONTRIBUTING.md), and [Contributor License Agreement](https://github.com/Ctrlpanel-gg/panel/blob/development/CONTRIBUTOR_LICENSE_AGREEMENT). The guide requires a signed CLA before a contribution can merge. Check the current upstream policy when submitting: these docs describe the policy checked with 1.2.0.

If you want to publish an addon rather than change the panel itself, start with [theming](/docs/theming) or [extension development](/docs/extensions). Existing addons are available through the [marketplace](https://market.ctrlpanel.gg/). The [roadmap](https://github.com/orgs/Ctrlpanel-gg/projects/1) shows planned work; use [Discord](https://discord.gg/ctrlpanel-gg-787829714483019826) for community questions.
